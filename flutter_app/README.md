# CCTV Attendance - Flutter companion app

A mobile app for the AI CCTV attendance system's admin/HR staff. It talks
to `api.py` (see the backend folder) over the `/api/v1/*` REST API.

## Features

- **Login** - sign in with the same admin username/password as the browser
  dashboard, against your own server URL (so this works with any
  deployment, not a hardcoded address).
- **Dashboard** - live camera snapshot (auto-refreshing), today's
  present/absent/currently-inside counts, and a feed of recent
  recognitions.
- **Attendance** - pick any date and see who was marked present and when.
- **Movements** - entry/exit log for any date.
- **Employees** - searchable directory with thumbnails; tap anyone for
  their profile and last 30 days of attendance.
- **Enroll** - add a new employee from the phone's camera: fill in their
  details, then a guided 5-pose capture flow (front/left/right/up/down,
  10 shots each) that mirrors the server's own quality checks (blur,
  face size, single face, correct head angle) in real time, then builds
  their face embeddings so they're recognizable on the entrance camera
  immediately.

## Getting started

This repo contains the Dart source (`lib/`) and `pubspec.yaml` only - the
native Android/iOS project folders are generated by the Flutter tool, not
hand-written, so:

```bash
flutter create --org com.yourcompany --project-name cctv_attendance_app .
flutter pub get
```

That regenerates `android/` and `ios/` around the existing `lib/` folder
without touching it. Then add the platform permissions below before
running.

### Android (`android/app/src/main/AndroidManifest.xml`)

Add inside `<manifest>`, above `<application>`:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-feature android:name="android.hardware.camera" android:required="false" />
```

If your server uses plain `http://` (no TLS) on a local network, also add
`android:usesCleartextTraffic="true"` to the `<application>` tag, or add a
network security config - otherwise Android blocks the request.

### iOS (`ios/Runner/Info.plist`)

Add:

```xml
<key>NSCameraUsageDescription</key>
<string>Camera access is needed to capture face photos when enrolling an employee.</string>
```

If your server is `http://` rather than `https://`, you'll also need an
`NSAppTransportSecurity` exception for local network access.

## Run

```bash
flutter run
```

On first launch, enter your server's URL (e.g. `http://192.168.1.10:8080`,
the same host/port `api.py` is running `PORT` on) and your dashboard
admin username/password.

## Project layout

```
lib/
  main.dart                    - app entry, theme, login-state routing
  models/models.dart           - JSON models (Employee, AttendanceRecord, ...)
  services/api_service.dart    - all HTTP calls + token storage
  widgets/session_helper.dart  - shared "token expired -> log out" handling
  screens/
    login_screen.dart
    home_screen.dart           - bottom-nav shell
    dashboard_screen.dart
    attendance_screen.dart
    movements_screen.dart
    employees_screen.dart
    employee_detail_screen.dart
    enroll_screen.dart         - details form + camera capture flow
```
